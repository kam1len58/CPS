# **Time Tracking System for Students**
Система для автоматизированного учёта времени, затраченного студентами на учёбу, проекты и дедлайны. Позволяет студентам отслеживать время, потраченное на различные учебные активности, прогнозировать дедлайны и генерировать аналитические отчёты.

## Технологии
Java 17

Spring Boot 3.5.5 (+Sping Security)

MVC архитектура

PostgreSQL для базы данных

Maven

Дополнительные библиотеки (Telegram Bots API, JXLS, Thymeleaf)

## Основные функции
1. Аутентификация и авторизация
2. Управление студентами
3. Управление временными записями
4. Прогнозирование дедлайнов
5. Отчётность
6. Загрузка данных

## Сборка и запуск
```
.\mvnw.cmd clean install
```
```
.\mvnw.cmd spring-boot:run
```
