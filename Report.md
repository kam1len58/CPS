# Time tracking system for students

В течение семестра мной была разработана система для автоматизированного учёта времени, представляющая из себя веб-приложение, разработанное на базе Spring Boot. Система позволяет студентам отслеживать время, потраченное на различные учебные активности, прогнозировать дедлайны и генерировать аналитические отчёты.

В ходе работы были рассмотрено много тем, которые я видел впервые.

Проект построен на базе Spring Boot 3.5.5, Java 17. Spring позволяет проще конфигурировать приложение и представляет встроенный сервер, запускающийся с запуском проекта. Он позволяет легко и просто внедрять зависимости Maven через конфигурационный файл pom.xml.

## MVC

Используется архитектура MVC. Модели содержат описание сущностей. Контроллеры обрабатывают запросы, логика которых расписана в сервисах, использующих методы репозитория для доступа к данным через Spring JPA. Для передачи данных используются DTO.

Для каждой сущности кроме токенов были созданы CRUD-операции и отдельные логические методы, реализующие основной функционал программы

Безопасность в проекте построена на Spring Security с использованием JWT-токенов (access и refresh), хранящихся в куки браузера для защиты от перехвата. Кастомный фильтр-чейн для проверки токенов на каждом запросе. Stateless-сессии без хранения состояния на сервере.

## Загрузка файлов

Система поддерживает загрузку и обработку CSV-файлов для импорта большого количества устройств пользователей или версий приложения. Это реализовано через MultipartFile и библиотеку Apache Commons CSV, позволяющей читать соответствующие файлы и выносить данные из них. Изначально файлы проходят валидацию (формат, размер, содержимое), затем сохраняются с именем, содержащим время загрузки. После этого их данные парсятся по заголовкам и создаются новые экземпляры сущностей. В случае возникновения ошибок они будут предоставлены пользователю с номерами строк, которые не удалось импортировать.

## Генерации Pdf-отчётов

Для генерации Pdf-отчётов используется библиотека JasperReports, создающая их на основе заранее подготовленного шаблона таблицы. Шаблон заполняется данными из Java-объектов через контекст данных, переводится в массив байтов и затем возвращается пользователю с возможностью скачать готовый файл. В отчёт входят данные об студентах, какие задачи они выполняли и сколько тратили на это время, JasperReports позволяет гибко форматировать шаблоны и поддерживает заполнение данных прямо из списка объектов, в данном проекте применяется лишь базовый функционал библиотеки.

## Telegram bot:
В систему добавлена интеграция с телеграм-ботом для Уведомления о входе в систему и смене пароля, Команды для взаимодействия с ботом (/help, /chat_id, /send_logs_to_admin), Отправку логов администратору по запросу. Пользователь привязывает через команду /start свой TelegramId к пользователю в системе, затем он может получать сообщения в мессенджере.

Все запросы могут быть протестированы через SwaggerUI, где для каждого контроллера и метода было добавлено название и описание функций. Также в качестве документации к проекту прилагаются логическая и физическая схема базы данных системы.

## Итоги:

К полученным навыкам можно причислить:

- получение опыта работы с Spring Framework и освоение его базовых возможностей DI, IOC, Application Context, аннотаций для конфигурации, транзакций, кэширования, логирования (понимание их работы);
- опыт разработки приложения в рамках архитектуры MVC с использованием сторонних библиотек для ввода таких функций, как импорт данных из файла, выгрузка отчётов в формате pdf;
- понимание безопасности на основе совмещения использования Cookie и JWT-токенов для Stateless-аутентификации, цепочки фильтров, хешировании конфиденциальной информации (паролей);
- работа с базами данных PostgreSQL, создание диаграмм базы данных

Проект представляет собой комплексную систему учета рабочего времени, реализующую многоуровневую JWT-аутентификацию с ролевой моделью доступа через Spring Security, управление данными пользователей и рабочих записей посредством Spring Data JPA с поддержкой транзакций и кэширования, интеграцию с Telegram-ботом для уведомлений о событиях системы, генерацию отчетов в форматах PDF и XML, а также обработку файловых операций с импортом/экспортом данных.
